Sanolagani is a web-based platform designed to connect startups seeking capital with potential investors by facilitating equity-based funding. The platform aims to streamline the investment process, providing startups with the tools to present their business proposals and investors with the means to evaluate and invest in promising ventures.

🔍 Key Features
Startup Profiles: Startups can create detailed profiles, showcasing their business models, financials, and growth plans.

Investor Dashboard: Investors have access to a personalized dashboard to track their investments and receive updates.

Equity Management: The platform includes tools for managing equity distribution and tracking investment rounds.

Secure Transactions: Implements secure protocols to ensure the safety and confidentiality of all financial transactions.

🛠️ Technologies Used
Backend: Java, Spring Boot

Frontend: HTML, CSS, JavaScript

Database: MySQL

Version Control: Git

📂 Project Structure
src/: Contains the source code for the application.

pom.xml: Maven configuration file for managing project dependencies.

.gitignore: Specifies files and directories to be ignored by Git.
